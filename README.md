# AccessGenealogy WordPress REST API - Postman collection

[Access Genealogy](https://accessgenealogy.com) publishes free transcriptions (Revolutionary soldiers by state, tax and census lists, county histories, Native American histories). The site runs WordPress and its REST API is open.

## Import
In Postman: **Import > Link** and paste
`https://raw.githubusercontent.com/mikeyeves/AccessGenealogy-API-Postman/main/AccessGenealogy_WordPress_REST_API.postman_collection.json`

## Requests
| Request | Use |
|---|---|
| Site search | find pages by word |
| Posts by keyword | titles and links |
| One post with content | read a transcription |
| Categories / posts in a category | browse a state or topic |
| API index | all routes |
